## <img src="https://host.mudi.bio/mudi-emoji/profile.png" width="25" height="25" align="center"> About Me

I'm **Mudi**, a Full Stack Developer focused on creating clean, functional and visually polished software.

I work across **web development, FiveM, automation, backend systems, Discord development and custom tools**.

I enjoy taking ideas from concept to completion — whether it's a small utility, an automated workflow, a custom FiveM system, a dashboard or a complete web application.

My goal is simple: build software that **looks good, performs well and is actually enjoyable to use**.
